# K-pop 女團入坑指南

生成式 AI 課程作業。給很少接觸 K-pop 的朋友看的女團入坑小網站：每團都有一句話介紹、團體特色、入門歌曲、推薦舞台和成員亮點。

- 製作方式：先寫 `CLAUDE.md` 規則，再請 AI 依規則製作網頁
- 技術：原生 HTML、CSS、JavaScript
